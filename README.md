<summary><b>1. Obrix — Intelligent Location Intelligence Platform</b> <code>React 18</code> <code>GeoDjango</code> <code>PostGIS</code> <code>Groq LLM</code> <code>Docker</code></summary>
<br />

* **One-Line Pitch**: Enterprise-grade geospatial decision engine and commercial site-suitability analytics platform combining spatial math with Generative AI.
* **Problem**: Retailers and commercial planners traditionally evaluate locations via manual surveys and fragmented maps, resulting in high capital risk, biased site selection, and zero quantified foot-traffic proxies.
* **Solution**: Engineered an automated spatial analytics platform that ingests OpenStreetMap vector data, executes spatial queries in PostGIS, runs multi-criteria mathematical scoring models, and delivers instant LLM-powered SWOT reports.
* **Architecture**:
  - *Frontend*: React 18, Vite, React-Leaflet, CartoDB Dark Matter layers, Zustand state store, Recharts radar breakdowns.
  - *Backend*: Python 3.11+, GeoDjango (`django.contrib.gis`), Django REST Framework, SimpleJWT role authentication.
  - *Data & GIS*: PostgreSQL with PostGIS extension for spatial index queries (ST_DWithin, ST_Distance), Overpass API spatial pipelines.
  - *AI Intelligence*: Groq Cloud SDK invoking `llama-3.3-70b-versatile` for real-time spatial SWOT synthesis.
* **Engineering Rigor**:
  - Formulated distance-decay mathematical scoring algorithms with competition density penalties tuned across commercial archetypes (Cafes, Pharmacies, Supermarkets).
  - Implemented client-side coordinate caching to minimize upstream Overpass QL rate limits.
  - Configured full containerization with Docker and multi-stage builds.
* **Security & Performance**: Strict JWT refresh rotation, CORS origin isolation, parametric spatial queries preventing SQL injection, and asynchronous client state transitions.
* **Learnings**: Mastering PostGIS spatial coordinate indexing, GeoJSON serialization pipelines, and prompt grounding techniques to eliminate LLM hallucinations on geospatial metrics.
* **Roadmap**: Implementing Redis layer for geospatial query caching and integrating demographic census overlays.
* **Links**: [GitHub Repository](https://github.com/Yash19k/Obrix-Location-Intelligence-Platform) • [Live Production Demo](https://obrix-frontend.onrender.com/)

* **Problem**: Most itinerary builders lack granular day-wise budget calculations, resulting in planning fragmentation across spreadsheets, notes, and calendar apps.
* **Solution**: Developed a multi-city travel planning platform enabling real-time expense calculations, day-to-day timeline visualization, public itinerary sharing, and responsive user settings.
* **Architecture**:
  - *Frontend*: React 19, TypeScript, Vite, Tailwind CSS, TanStack Query v5 for server-state caching, React Hook Form + Zod schema validation, Lucide icons.

* **Learnings**: Building large-scale TypeScript type hierarchies, mastering TanStack Query optimistic updates, and maintaining disciplined test coverage.
* **Roadmap**: Implementing collaborative multi-user editing via WebSockets and downloadable PDF summary generation.
